# Real vs Fake Face Detection

This project trains and compares four image classifiers that decide whether a face photo is a **real photograph** or **AI-generated (GAN) fake**. The models are a custom CNN plus three ImageNet-pretrained networks: ResNet50, EfficientNet-B0 and DenseNet121.

Everything is in one notebook: `da_proj.ipynb`.

## Dataset

[140k Real and Fake Faces](https://www.kaggle.com/datasets/xhlulu/140k-real-and-fake-faces) on Kaggle, by xhlulu. It has 70k real faces from the Flickr-Faces-HQ (FFHQ) dataset and 70k fake faces generated by StyleGAN.

The notebook downloads the dataset automatically with `kagglehub`. To keep training fast, it uses a balanced random subset:

| Split      | Real | Fake | Total |
|------------|------|------|-------|
| Training   | 750  | 750  | 1,500 |
| Validation | 750  | 750  | 1,500 |

You can change the subset size with `N_PER_CLASS` in the data loading section. Labels are **0 = Real** and **1 = Fake**.

## Models

| Model | Type | What gets trained |
|-------|------|-------------------|
| CNN | Custom, from scratch | All layers: 4 conv blocks with BatchNorm and LeakyReLU, then a 3-layer classifier with dropout |
| ResNet50 | Pretrained on ImageNet | `layer4` and a new classifier head |
| EfficientNet-B0 | Pretrained on ImageNet | The last 6 feature blocks and a new classifier head |
| DenseNet121 | Pretrained on ImageNet | `denseblock4` and a new classifier head |

Images are resized to 64×64. The pretrained models resize them again to 224×224 inside their `forward` method. Training images are augmented with horizontal flips, small rotations and color jitter.

## Training setup

- **Loss:** binary cross-entropy (sigmoid output)
- **Optimizer:** AdamW, weight decay 0.01
- **Learning rate schedule:** OneCycleLR, max learning rate 0.001
- **Epochs:** 10 per model
- **Batch size:** 32 for training, 64 for validation
- **Gradient clipping:** by value, 1.0
- **Checkpoints:** saved after every epoch (`<model>_checkpoint.pth`), so training can resume if it's interrupted

## Evaluation

Each model is scored on the validation set by accuracy, precision, recall, F1 score and a confusion matrix. The notebook produces:

- training and validation curves for every metric
- side-by-side confusion matrices
- a bar chart comparing the models
- sample predictions from each model on the same validation images
- `model_comparison_results.csv`, a summary table of all models

## How to run

1. Open `da_proj.ipynb` in [Google Colab](https://colab.research.google.com/).
2. Go to **Runtime → Change runtime type** and select a **GPU**. Training on a CPU is very slow.
3. Run all cells from top to bottom. The dataset and the pretrained weights download automatically.

To run it locally instead, install the requirements:

```bash
pip install torch torchvision kagglehub scikit-learn matplotlib seaborn pandas tqdm
```

`kagglehub` needs Kaggle API credentials to download the dataset. See the [kagglehub docs](https://github.com/Kaggle/kagglehub).
